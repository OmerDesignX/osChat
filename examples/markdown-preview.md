# Markdown preview

osCode renders GitHub-style Markdown locally. Mermaid diagrams are processed on this computer and can be copied or saved as SVG or PNG.

```mermaid
flowchart LR
  Project[Open project] --> Edit[Edit Markdown]
  Edit --> Preview[Local preview]
  Preview --> Export[Copy or save diagram]
```

| View    | Purpose                       |
| ------- | ----------------------------- |
| Edit    | Write Markdown                |
| Split   | Write beside the live preview |
| Preview | Read with maximum space       |
